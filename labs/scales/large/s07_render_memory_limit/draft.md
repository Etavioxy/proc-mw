# 场景 S07 · 独立草稿 —— 渲染批次内存限制

## 用户故事
> 作为**性能**，我想**渲染事件内存有上限**，以便**大量粒子/精灵不撑爆内存**。

## 设计决策
1. **上限热更**：v1（>1000 拒）→ v2（>500 拒，收紧），`chain.set` 热替换。
2. **直接依赖宿主**（usergoals）：`large_service::RenderBatch`。
3. **超上限 = 返回码 2**（批次不达渲染队列，内存有界）。

- 纯函数校验（无状态）——插件无状态，热更安全。
