# 场景 S10 · 独立草稿 —— 动画状态机熔断

## 用户故事
> 作为**玩法**，我想**动画状态转换出错时熔断**，以便**卡死动画自动回退默认态**。

## 设计决策
1. **CircuitBreaker::call_opaque 包装链**：连续转换失败 ≥ 阈值 → 打开（快速失败）→
   冷却 → 半开放行 → 恢复。
2. **Flaky 节点**模拟转换失败；转换插件（运行期编译）标记 ok。
3. **直接依赖宿主**（usergoals）：`large_service::AnimTransition`。

## 待测试点
- [x] 3 次失败 → 熔断打开 → 第 4 次快速失败。
- [x] 冷却后半开放行成功 → 恢复。
- [x] bevy 只收成功转换。
- [ ] 熔断回退默认动画（open 时走默认态）。

## 边界反思
- 熔断在宿主包装层（状态跨热更保留）；转换规则是可热更插件。
- 快速失败路径不达 bevy（动画回退默认态由场景处理）。
