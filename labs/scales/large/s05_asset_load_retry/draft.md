# 场景 S05 · 独立草稿 —— 资源加载重试

## 用户故事
> 作为**渲染**，我想**资源加载瞬时失败自动重试**，以便**CDN/IO 抖动不导致模型丢失**。

## 设计决策
1. **exec_retry**（opaque 语义原语）：链失败（返回码 2）重试至多 N 次，每次从原始请求
   克隆重放（非幂等变换不累积）。
2. **Flaky 宿主节点**模拟瞬时加载失败；加载插件（运行期编译）标记 loaded。
3. **直接依赖宿主**（usergoals）：`large_service::AssetLoad`。

## 待测试点
- [x] 瞬时失败+retry5 → 3 资源全部加载。
- [x] 失败3次+retry1 → 耗尽透传。
- [x] 成功事件进 bevy，失败不进。
- [ ] 熔断保护（连续失败 → 打开）。

## 边界反思
- 重试状态在宿主（Flaky 节点）；加载逻辑是可热更插件。
- exec_retry 的克隆重放保证重试不重复加载副作用。
