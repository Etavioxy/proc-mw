# 场景 S06 · 独立草稿 —— 存档校验

## 用户故事
> 作为**玩家**，我想**损坏/作弊存档被校验拦截**，以便**坏存档不污染游戏世界**。

## 设计决策
1. **校验规则热更**：v1（拒负金币）→ v2（拒负金币 + 超上限 999_999），`chain.set` 热替换。
2. **直接依赖宿主**（usergoals）：`large_service::SaveData`。
3. **违规存档 = 返回码 2**（不达 bevy）。

## 边界反思
- 校验规则是可热更插件（策略变化即时生效）；校验状态无（纯函数）——插件无状态。
- 校验规则热更 = 合规策略运行期调整。
