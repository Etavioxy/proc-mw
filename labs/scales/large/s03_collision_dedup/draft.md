# 场景 S03 · 独立草稿 —— 碰撞事件去重

## 用户故事
> 作为**物理**，我想**同帧重复碰撞事件去重**，以便**伤害结算不被重复触发**。

## 设计决策
1. **去重状态在插件内**（运行期编译，任意 Rust）：`OnceLock<Mutex<HashSet<(u32,u32)>>>`
   记已见碰撞对；归一化 (min,max) 使双向碰撞视为同对。
2. **直接依赖宿主**（usergoals）：`large_service::CollisionEvent`。
3. **去重 = 返回码 2**（重复对不达 bevy 事件系统）；bevy 消费者只收 resolved 事件。

## 待测试点

- [x] (1,2)/(2,1) 归一化同对去重。
- [x] 插件内 HashSet（任意 Rust 状态）。
- [x] metrics 计数 4。

## 边界反思
- 插件状态（HashSet）跨热更归零（有状态插件热更边界，见 tests/opaque.rs）；
  若去重需跨热更保留，状态应落宿主 Stateful 节点。
- 永久去重 vs 窗口去重：游戏需窗口（每帧重置），此处为演示永久去重。
