# 实验 03 · D3 动态性 · 数据/快照层增删（RCU）— 验证结果

> 日期：2026-08-06 · 工具链：rustc/cargo 1.94.1 · 平台：Apple Silicon (ARM64)

## 结论：D3 达到极致 ✓

**增删是数据层的快照替换，读路径在机器码上与裸 `&[Node]` 迭代只差一次 Arc 指针加载——无锁、无分配、无额外指令。**

## 多重测试

### T1 · 增删快照多步序列行为正确
`Chain = [Add(1), FnPtr(mul3)]` 逐步增删，每步结果断言：
- 初态 `exec(5) = 18`（(5+1)×3）✓
- `add(Add(10))` → `exec(5) = 28` ✓
- `remove(0)` → `exec(5) = 25` ✓
- `add(FnPtr(mul3))` → `exec(2) = 48` ✓

### T2 · 读路径与裸 `&[Node]` 等价（4 样本）
`exec(Arc 快照) == exec_bare(&[Node])`，x ∈ {-10, 0, 5, 1000} 全一致 ✓

### T3 · 写路径 Θ(len)
| 链长 | add 平均 |
|---|---|
| 10 | 3.43 μs |
| 100 | 3.24 μs |
| 1000 | 3.50 μs |
| 10000 | 7.49 μs |

复制成本随链长增长；常量（3μs 级）来自 `Vec::clone` + `Arc::new` 堆分配，数据部分线性。符合"Θ(len) + 稀有操作"承诺。

### T4 · 并发安全（4 读者 + 1 写者）
- 读者：400 万次 `exec`（无锁，取一致快照）
- 写者：5 万次 add/remove（复制快照 + Arc 替换）
- 断言：结果无撕裂（`exec(0) ≥ 0` 弱不变量）、无 panic ✓

## 读路径机器码证据（Release，`--emit=asm`）

```asm
; exec（Arc 快照）                              ; exec_bare（&[Node]）
str w1, [sp, #12]      ; 存 ctx.x              str w2, [sp, #12]     ; 存 ctx.x
ldr x8, [x0]           ; ← 唯一差异：Arc deref  cbz x1, LBB40_6       ; len==0?
ldr x9, [x8, #32]      ; Vec.len               lsl x19, x1, #4       ; len*16
cbz x9, LBB39_6                                add x20, x0, #4       ; data+tag
ldr x8, [x8, #24]      ; Vec.data              ...
```

**差异 = 1 条 `ldr`（Arc 指针解引用）。** 之后迭代完全相同——快照读取的零成本在汇编层得到证明。

## 对 D3 约束的判定

| 承诺 | 判定 | 证据 |
|---|---|---|
| 增删只在数据/快照层 | ✓ | add/remove = `Vec::clone` + `Arc::new` 替换 |
| 读路径无锁、无分配、零成本 | ✓ | 与裸迭代只差 1 条 `ldr`，无锁原语、无堆分配 |
| 写路径 Θ(len) 且有界 | ✓ | 3.4→7.5μs（10→10000 元素），分配常量 + 线性数据 |
| 实例增删（非类型新增） | ✓ | `Node` 闭合枚举，类型集合编译期固定 |

## 一句话

D3 的快照模型付出的全部读路径成本是**一条指针加载**——这让 D4 的"空链透明（含 Debug）"有了机制前提：读路径上根本没有锁和分配可以拖慢空链。
